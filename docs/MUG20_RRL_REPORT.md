# 杯子20残差强化学习阶段报告

整理日期：2026-11-05。仅核对已保存结果，未启动训练或仿真。

## 结论与完成边界

杯子20阶段性工程验证已完成，归档为回归参考，暂不继续围绕它扩大训练。v4保留了已测初始位置扰动下的六方向通过能力，部分尾部滑移和转角改善；常态误差与部分mimic误差增大，不能声称策略全面优于零残差。基线在已测样本中已经全通过，因此没有证明失败抓取修复或成功率提升。

当前主任务切换为杯子原始下标0：先复核当前RL零残差，确认重力阶段失败后再独立训练。杯子20或积木7的检查点不直接用于杯子0。

## 任务、控制与验收

- 身份：mug，生成结果原始下标20，scale=0.05999999865889549；固定手腕，每个reference独立策略。
- 后端：原生Isaac Sim、SDF256碰撞及物理mimic；物体源为恢复的CoACD网格，SDF不能恢复源资产已丢失的细节。
- 协议：零重力闭合2秒、稳定1秒，随后重力保持10秒；切换时不重置物体状态。
- v2–v4：120维观测；16维主动关节残差，仅重力有效阶段学习。策略60Hz、物理240Hz；目标残差幅值0.15rad，目标残差限速0.2rad/s，后者不是实际关节速度硬上限。
- PD：Kp=5、Kd=0.05；物理、控制与严格验收不因奖励版本改变。
- 严格成功：准备阶段获取接触，重力阶段最大滑移≤5mm、最大转角≤15°，全采样过程穿透≤1mm，末尾连续1秒接触且数值有限。mimic误差作为额外诊断，不把未规定的阈值编成成功条件。
- 配对：每轴均匀初始平移±0.5mm；零残差与确定性策略读取同一扰动表并检查显式初态一致。相同显式初态不保证PhysX内部状态逐位一致。

### 为什么不能仅凭最差值改善认定策略更好

原样本中v4策略滑移中位数1.1170mm，而基线仅0.0687mm；其最差滑移则由3.0100mm降到1.7491mm。原样本mimic最大误差约0.0328rad，基线约0.0177rad。
新seed中策略滑移中位数1.3775mm，基线0.1849mm；最大滑移由4.3643mm降到3.1935mm。策略mimic误差中位数约0.0086rad，基线约0.0053rad。
策略可能用持续偏置换取部分尾部稳定性，需结合原始动作、请求残差、限速后目标和实际关节运动判断；这些数据已保存在240Hz诊断文件。尾部改善在新seed重复出现，仍不足以证明总体收益或真实部署鲁棒性。

## 本阶段学到的工程能力与下一任务

1. 将训练结束、奖励升高、接口检查通过与完整动力学成功分开。
2. 先用零残差建立可复现基线，按相同样本做配对，再比较连续误差。
3. 奖励、历史观测、终止与严格验收须一致；对奖励修改先检查失败激励。
4. 对成功参考，RRL意义是保留能力或改善稳定裕量，不能凭100%对100%声称成功率提升。
5. 下一阶段杯子0要验证：重力失败可复现、残差来得及干预、修复失败且不破坏原能力。先做同样本，再固定检查点测试新seed；证明RL必要性还需简单控制器对照。
