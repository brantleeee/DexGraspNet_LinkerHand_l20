# 中指接触重选：实现与完整结果

2026-11-16。实现脚本`reselect_l20_middle_contacts.py`，不改原生成器或mesh_gap对照。已运行四构型320组合及原60构型4800组合，完整目录：`data/experiments/l20_contact_reselect_full_check_20261116`。

## 已实现的行为与复现检查

验证源静态网格完整性及已记录源文件/模型散列，加载原物体表面采样而非重采样。按源行号重建MCP/PIP、DIP按mimic投影，其余关节和腕不变。复算穿透和/最大值与缓存对照，复用不因接触点变化而改变的几何准入。计算80个中指点的四槽组合，其他三槽保持371/316/151。

E_fc拆为原返回法向的近似合力及合矩范数平方，直接与原contact_terms核对；固定槽总目标与原保存值核对，固定槽全局选择必须复现原24/45行，否则报错。没有把几何拒绝构型重新准入。

区域标签默认unknown；支持`--region-labels`提供带contact_points.json散列的注释，标签只记录，不改变A/B可行域。不能自动认证掌侧或稳定性。重选参考中明确标记`dynamics_admitted=false`，待有效区域、独立绝对几何和闭合路径检查。没有开始36次动力学。
