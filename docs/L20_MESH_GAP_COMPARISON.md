# 真实网格间隙排斥：独立静态对照

2026-11-16。脚本`compare_l20_mesh_gap.py`固定手腕及其他手指，仅搜索中指MCP/PIP，DIP按原mimic跟随。两种目标读取同一接触集合、物体采样、局部构型网格与准入条件，分别选择最低目标值构型。不是重新训练、优化器收敛测试或动力学验证。

## 行为

- legacy使用原20mm关键点自排斥；mesh_gap使用非相邻原始三角网格的间隙惩罚`sum(max(0,margin-gap)^2/margin)`，米制、权重10。默认margin=1mm是实验参数，尚未硬件标定。
- 三角网格间隙由AABB筛选、顶点—三角形及边—边距离、三角面相交测试计算，截断在margin。输出等于margin表示至少该间隙，不是完整最小距离。
- 两组共同拒绝中指与任何其他指（含拇指、小指）、掌部及非相邻本指连杆的表面相交/接触，或在可判定闭合目标中检出的包含。URDF直接邻接作为结构允许对排除，清单写入config。开放网格的包含未知会明确记录，未作实体无碰撞认证。
- 共同拒绝原E_pen采样和或原手部凸包对物体采样的最大内部值超过参考值1e-6m的构型。初始参考本身可能已穿透；非增加不等于绝对合格。该护栏还是原生成代理，不能宣称真实手物穿透完全不增加。
- 接触固定为grouped4的同一组（拇指、食指、中指、无名指/小指池），不会因目标改变而重采样。probe-index可换其他预先保存的受控样本；旧最终接触未知。
- 输出完整网格结果、选择结果、源文件散列、原物体点和HTML。没有修改原生成器、模型或旧NPY。两组不同损失值不可直接比较大小，应看各自选择构型及共同几何指标。

## 命令

```bash
cd /home/lee/DexGraspNet_LinkerHand_l20
l20_gap_out="data/experiments/l20_mesh_gap_compare_$(date +%Y%m%d_%H%M%S)"
.venv_l20/bin/python scripts/compare_l20_mesh_gap.py \
  --candidates 22 18 \
  --mcp-angles 0 0.2 0.4 0.5 0.6 0.7 0.8 0.9 1.0 1.1 \
  --pip-deltas -0.2 0 0.2 \
  --margin-mm 1 --surface-samples 2000 \
  --seed 1 --probe-index 0 \
  --output "$l20_gap_out"
cat "$l20_gap_out/REPORT.md"
xdg-open "$l20_gap_out/index.html"
```

需要CUDA。输出目录须新建；该命令会逐构型检查真实三角面，比纯能量扫描慢，终端会逐行报告，不需要代理持续监控。若没有合格构型，选择为空，不能当成功。
