# 当前Isaac Sim动力学验证与DexGraspNet官方Gym验证的区别

日期：2026-11-08。依据本仓库官方代码副本及当前实际配置；“官方Gym”指ShadowHand原验证代码，“L20 Gym适配”指本工程修改后的复现实验，两者分别说明。

同批80候选已补充[480方向统计、坐标系定义及mug0组3曲线](GRASP_DIRECTION_COMPARISON_20261108.md)，包含1/6至5/6部分成功。

## 1. 核心区别

官方流程主要筛选：**给定抓取状态经过短时六方向重力仿真后，末帧是否仍有手–物接触，同时静态穿透能量是否合格。**

当前Isaac Sim流程检验：**手指能否在零重力下建立接触，并在随后10秒六方向重力测试中持续满足滑移、转角、动态采样穿透和末段接触条件。**

两者都做物理验证；不能将原方法描述为只看静态姿态。当前协议增加过程与持续保持条件，但同时改变模型、控制和时长，因此通过率不是公平的引擎/算法排名。

### 2.1 当前如何判定“稳定抓取”

以下对应当前杯子0/RRL的acquire协议：0–2秒闭合，2–3秒稳定，3–13秒重力保持。不是“视频末帧杯子还在手里就算成功”，也不是奖励超过某个数值。

**一个方向必须同时满足全部条件：**

|条件|判定时间与计算|通过要求|
|---|---|---|
|数值有效|逐物理步检查物体/关节状态及接触量|不得出现NaN或Inf；数值异常不能冒充通过|
|获取接触|3秒、开启重力前的最后状态|手–物接触记录数>0；此处只看记录数，不要求五指接触，也不要求法向力已超过0.001N|
|重力平移稳定|以3秒时实际物体位置p₀为参考，逐步计算‖p(t)−p₀‖|整个10秒重力阶段最大值≤0.005m，即5mm|
|重力转角稳定|以3秒时实际物体四元数q₀为参考，角差为2 arccos(clamp(\|q(t)·q₀\|,0,1))，转为度|整个重力阶段最大值≤15°；四元数正负表示同一朝向|
|动态穿透受限|从闭合开始到结束的每个采样步，依据接触分离距离取max(0,−最小separation)|全程采样最大值≤0.001m，即1mm，不是只看最终穿透|
|末段接触保持|最后240个物理步，即最后1秒|每个采样步的接触力指标都严格>0.001N；力指标为各手部连杆接触法向合力向量模长之和|
|完整运行且无历史失败|全部3120物理步结束|上述严格失败记录均未触发；最后恢复接触不能清除先前超限|

**参考时刻很重要。** 平移和转角相对开重力前实际姿态计算，不是相对物体原点或最初未扰动姿态。零重力阶段物体推移另作诊断，并没有单独的5mm获取阶段位移限制；但穿透限制覆盖获取阶段。阶段切换不重置位姿或速度。

**持续接触的范围。** 当前不要求整个10秒始终有非零力；早期短暂丢接触，只要未触发其他严格失败且最终能形成完整末1秒连续接触，可以通过。RRL历史逻辑会在剩余时长已不可能补齐240步连续接触时提前记录last_second_contact失败。

**历史失败不可逆。** 任一时刻滑移>5mm、角差>15°或采样穿透>1mm，或者3秒未获取接触，即记录失败；失败环境的策略更新被屏蔽，物理仍可能继续运行并保存到统一结束。因此视频后面重新碰到杯子也不算修复。dropped是更宽的掉落诊断（滑移>50mm或转角>90°），不是通过阈值；超过5mm时早已失败。

**六方向与样本层级。** 一个平移样本要在gx+、gx−、gy+、gy−、gz+、gz−六方向全部通过，才算“完整六方向稳定”。5/6只表示五个方向成功，不表示该样本完成六方向验收。多个平移再分别统计完整成功组数；方向通过率、平移完整成功率和不同抓取候选成功率不可混用。

**以下不是当前硬验收条件：**

- 接触点多或瞬时接触力大；掌根有接触记录；五个手指是否全接触。
- mimic误差、关节速度、残差幅度及物体预加载推移的独立诊断统计（控制器本身仍施加约束/限速）。
- 奖励、PPO损失、训练迭代数、视频看起来是否平稳。

mimic及运动代价仍须报告，避免“通过了但控制质量变差”。持续多指受力也不等于已经证明力闭合或抗任意扰动稳定。

**验收与证据可信度分开。** 零–零过程复现、策略干预前前缀一致、资产/检查点散列是对照实验有效性的门控，不是物理成功阈值。物理6/6而过程不匹配时，可以描述该次运行结果，但不能将两组差异可靠归因于策略。1mm穿透也是离散240Hz接触采样标准，不保证连续时间全部几何穿透都被检测。

### 2.2 官方Gym的“通过”不能替代上述稳定定义

官方本地代码的批量判断为：六方向仿真结束时均存在手–物接触，且保存的静态E_pen<0.001。它没有以整个10秒内5mm/15°及末1秒连续接触作为该代码的筛选条件；静态E_pen筛选也不是对仿真过程中全部动态接触穿透的测量。

因此汇报应明确说“通过本工程规定的六方向10秒稳定性验收”，而不是“证明绝对稳定”或“等同官方Gym成功”。

## 3. 官方接触调整不是闭合轨迹规划

官方 validate_grasps.py 从手部表面点寻找距离物体较近的点，按法向构造约1mm位移目标，通过损失梯度调整关节状态；默认grad_move=500，--no_force跳过调整。随后把调整后的关节状态传给验证器，验证器设置初始关节状态和位置控制目标。

这是仿真前的几何关节修正，不是“先张开、逐步闭合、根据实时接触反馈调整”的完整时序控制，也不是RRL策略。

当前保持消融同样不是重新训练：它改变冻结策略的执行方式，需独立报告其单组验证范围。

### 3.1 官方批量验证的实际顺序：没有“先张开再闭合”

1. **读取生成姿态q。** 这是已经接近抓取构型的ShadowHand关节角，不是张开的准备姿态。
2. **仿真前几何修正。** 默认对有表面采样点的连杆，选一个有符号距离最大的点；该距离约定物体内部为正，所以这是该连杆上距离判据最靠近/最深入的采样点。仅将满足距离门限的点纳入修正，不是使用仿真器实时接触力选点。代码最多使用19个连杆槽位，不代表最终有19个有效承载接触。
3. **计算一次关节调整。** 设选中手点为x(q)、代码法向为n，构造x_target=x(q)+0.001n，再令L=Σ‖stop_gradient(x_target)−x(q)‖²。代码实际执行 `q_new = q + 500 * ∂L/∂q`，仅改关节分量，不改保存的手腕位姿。这个加号按原代码保留，不能擅自改写成常规梯度下降。通过运动学梯度把点/法向要求映射到各关节，不是每个关节统一加固定角，也不保证实际点移动恰好1mm或每根手指都闭合；这是有“抓紧”意图的启发式几何修正。
4. **直接加载修正后的姿态。** 默认批量调用将q_new作为hand_qpos传给add_env，没有另传target_qpos。因此初始关节位置和位置驱动目标都为q_new；--no_force则二者均为原始q。源码支持可选不同目标参数，但当前官方批量脚本没有使用它来生成张开到闭合轨迹。
5. **带重力运行物理。** PD位置驱动保持固定目标，刚度1000、阻尼0，通常运行100步。手指可以因接触力、数值约束和位置驱动响应而运动，但没有预先安排从张手到闭合的时间曲线，也没有在线重复几何修正或根据力反馈更新目标。
6. **按官方条件筛选。** 每个方向仅在run_sim结束查询是否有手–物接触，六方向都为真，再与原记录E_pen<0.001组合。这个筛选不要求本工程的历史5mm/15°及末1秒连续接触条件。

因此“官方抓紧修正”和“当前Sim闭合/RRL”处在不同层次：前者是仿真前一次静态关节改值，后者有实际2秒张开到闭合过程，并可由策略在后续阶段在线改目标。官方手指不是被焊死不动，但默认也不是从张开姿态逐渐抓杯子。

### 3.2 本工程改善抓取的方法：改参考、改残差、改时序

**第一层：接触几何不合适时，细化静态参考。** 改动主动关节参考角，必要时另优化手腕；从动关节按mimic重建，满足限位。作用是改变接触位置和手指包络，不是增加驱动力。已试食指/中指MCP各+0.015rad，组3由4/6→6/6，但新五平移修复3次也损害3次，因此没有晋升为通用改善参考。参考一旦改变，不可直接复用原参考训练的策略。

**第二层：用残差反馈修正原参考。** 当前策略60Hz读取关节误差/速度、物体相对位姿/速度、总接触力、时间与历史等120维观测，输出16维动作均值。它不直接输出电机力矩，也不直接读取逐指接触点/法向；逐指诊断数据不等于策略输入。

动作先转为 `d_request=0.15*tanh(a)` rad，预加载窗口再乘0.5，因此该阶段请求最大绝对值0.075rad（约4.30°）；重力阶段请求上限0.15rad（约8.59°）。每物理步以每关节有效速率r_i≤0.2rad/s更新已施加偏置：`d_next=d_prev+clip(d_request-d_prev, -r_i*dt, r_i*dt)`。最后 `q_target=project(q_reference+d_next)`。这让策略可以分别调整各指，不等于所有手指统一更闭合；目标偏置限速也不限制实际关节速度到同一数值。

PD驱动根据目标误差产生运动（可近似理解为Kp*(q_target−q)−Kd*qdot，实际由PhysX隐式求解）。本次改善没有提高Kp、摩擦或力矩限值；修正目标本身才是被改变的控制变量。

**第三层：提前建立接触。** v4只在3秒开重力后允许残差；v5提前到2.5秒。目标是在载荷到来前调整接触，而不是等几十毫秒内已经滑移超限再追赶。闭合0–2秒仍沿原参考，不能把它描述为RRL学出了整个接近/闭合轨迹。

**第四层：保持预加载中已形成的目标。** 组5策略曾建立短暂受力却在3秒前丢失，因此评估变体在2.6–3秒保持已施加偏置，不再跟随新的策略请求；3秒从该偏置连续恢复原策略。初始残差0、限速0.2rad/s意味着到2.6秒可积累的偏置量级至多0.02rad（还受各关节约束影响），不是突然跳到最大请求。固定位置目标仍可通过位置误差驱动手指，实际关节与物体没有锁死。

组5 gy+该变体使预加载推移2.086→0.836mm，开重力时仍有拇指/无名指/小指受力，10秒最大滑移46.728→1.167mm，严格失败→通过；支持保持阶段接触的局部作用。它是人工设定的执行规则与同一学习策略的组合，不是Actor自行学到的“2.6秒冻结”，也尚未证明所有平移都改善。

**如何决定改哪一层。** 几何上一直够不到物体，优先检查参考与尺度；目标变而关节不动，检查限位/mimic/驱动；曾受力但零重力中丢失，做预加载目标时序消融；加载后才滑移，检查接触布局、物体运动与目标响应。接触点多/力峰值大都不能替代严格保持验收，不直接用加刚度、加摩擦掩盖原因。

**尚待验证的改进。** 保持变体在其他平移上的成功保留、新的未参与调参样本，以及固定偏置/规则控制器对照。若进一步给Actor增加逐指接触观测，或加入新的预加载保持目标，需要独立任务版本和新训练，不能在原120维检查点上静默改变含义。当前证据说明该控制组合能修复部分失败，未证明RRL是唯一或必要方案。

## 4. 本工程的“official Gym”标签意味着什么

本工程 scripts/validate_l20_isaacgym.py 沿用官方测试参数与接触筛选思想，但手型替换为L20，并加入联动目标投影和相关适配。因此报告中的official表示**接触调整的L20适配协议**，不是未修改的官方ShadowHand实验。

该L20 Gym入口的21关节均位置驱动，mimic只约束目标，没有当前Sim中的硬物理耦合；手/物体采用Gym凸碰撞。no-force表示不做官方接触调整，并非没有位置驱动力。sim-steps=1000是用户扩展时长，不能称官方默认100步协议。

已完成的80候选对照中，Gym未调整8/80、调整9/80、Sim18/80全部六方向通过；由于模型与验收不等价，不能据此推断“Sim更好”或“Gym错误”。同一候选应逐方向检查差异来源。
