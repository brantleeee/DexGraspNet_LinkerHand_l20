# 中指MCP全范围扫描复盘（2026-11-16）

源实验：`data/experiments/l20_middle_mcp_range_20261116_125423`。两个候选均完成，MCP从0扫描至1.4rad；其他关节、手腕固定，PIP/DIP不变。本轮2000物体表面点与上一轮文件逐字节相同，便于比较。没有优化、动力学或训练。

## 现象与新结论

**两个候选在扫描角度中均存在中指接近物体的位置，当前证据不支持“单MCP全范围都不可接近”。下一关键问题是跨指排斥是否对应真实几何碰撞。**

|候选|原MCP rad|原中指最近接触候选距离 mm|出现接近的MCP rad|该处最近距离 mm|1mm内候选点数|
|---|---:|---:|---:|---:|---:|
|22|0|23.121|1.0|0.736|3/80|
|18|0|29.234|0.6|0.105|4/80|

这些是接触候选点到生成物体表面的距离，不是物理接触点或接触力。ObjectModel使用sqrt(d²+1e-8)，接近0时有约0.1mm数值底，不能把0.105mm解释为精确真实间隙。

22在0→.1rad最初变远，之后又靠近，修正了仅凭小范围扫描可能产生的不可达印象。局部梯度不能代表整个合法范围的可达性。

## 为什么探针目标不偏好这些接近姿态

在同一组固定接触探针中，移动到上述姿态时：

|候选/位置|跨指排斥加权增量|指掌排斥加权增量|全部自排斥加权增量|global4总能量增量|grouped4总能量增量|
|---|---:|---:|---:|---:|---:|
|22 / 1.0rad|+10.704|−.407|+10.297|+9.224|+8.953|
|18 / .6rad|+9.957|−.314|+9.643|+5.973|+8.000|

同连杆和相邻连杆损失基本不随MCP改变，屏蔽它们不会消除这段障碍。已有数据支持“跨指关键点排斥形成较大的目标代价障碍”，但**尚未区分合理的真实避碰与过于保守的20mm规则**。不同接触点的吸引变化也不同，上表扫描仅使用每种模式的第0组，不外推全部原优化轨迹。

在上述角度，2000物体点得到的原E_pen采样和没有比起点增加：22仍.00022148m、18仍.00130793m。这只说明这份物体采样未新增相应手部凸包内部损失，不认证无手物穿透；18中指候选点的原物体符号内部值已有约.290mm。

## 不能继续盲目增加MCP

- 22到1.2rad，中指候选点的原符号内部值最大约11.42mm；原E_pen采样和从.00022148增至.0209442m。
- 18到.8rad，相应内部值约9.07mm；E_pen采样和从.00130793增至.0194883m。
- 后续某些深角度的总探针能量反而下降，进一步说明总能量低不能替代几何合法性。原物体开放，符号深度仍需独立几何认证，不能直接当Isaac Sim最大穿透。

## 下一步：先检查8个冻结构型的真实跨指几何

优先测试22的MCP={0,.9,1.0,1.1}和18的MCP={0,.5,.6,.7}，保持其他关节和手腕不动；这些仅为静态诊断点，不是可执行闭合轨迹。

1. 对中指近/中/远节与食指、无名指、小指、拇指、掌部逐连杆记录三角面相交、可靠最近距离、是否属于允许的结构邻接。
2. 同时记录这些构型的关键点排斥分解及贡献最大的具体连杆对，导出原网格着色三维页面和网格身份；不能只看关键点距离。
3. 对手物接触采用同源碰撞表面作独立复核，显式区分生成手部凸包与原网格。开放网格及最近面法向符号不能认证内外，须使用适用的几何交叠/闭合代理或可靠物理碰撞审计。

决策：

- **若真实碰撞或间隙不足**：保留避碰，联合调整MCP/PIP（DIP跟随mimic），必要时加入MCP roll或小范围手腕调整，绕开障碍；不能直接把MCP设成1.0/.6。
- **若几何合法却被20mm规则强烈排斥**：新实验分支改用按连杆几何/间隙定义的排斥，进行接触分组单改、排斥单改、两者同改对照。不要凭外观任意将20mm减小或关闭整个自碰撞。
- **若接近物体但接触法向/位置不利**：先修接触选择，不能以“中指加入了”替代有效夹持。

这些检查之后再在22约.85–1.10rad、18约.45–.75rad做细化或MCP/PIP联合局部优化。先证明几何合法及其他指未退化，再做原600g、六方向、2+1+10秒Isaac Sim验证。

当前已有脚本只对原冻结姿态导出具体连杆对采样几何，扫描点未逐个做完整跨指碰撞审计；因此下一步需要扩展这部分诊断，尚未实现或宣称修复。当前不需再跑更大单MCP范围、相同16位姿动力学或RRL长训。
