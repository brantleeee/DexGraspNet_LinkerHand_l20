# 当前工程对 DexGraspNet 的扩展、改进与研究证据

更新日期：2026-11-08。本文区分已经实现的工程扩展、局部实验改善与尚待证明的研究贡献；不把功能增加等同于算法优越性。

汇报版材料及视频：[阶段进展汇报](GRASP_PROGRESS_REPORT_20261108.md)。最新单组保持消融已完成，见下文4.3；不与原RRL五平移结果混合统计。

## 1. 当前工作定位

本工程保留 DexGraspNet 的静态抓取生成主线，研究如何把生成结果变成 LinkerHand L20 上可执行、可诊断、可修复的动态抓取：

**静态生成 → 联动约束投影 → 抓取建立与长时验证 → 接触诊断 → 参考细化或残差策略修复 → 可复现配对评估。**

当前最有证据支持的结果是：以原始杯子候选0为参考，冻结的v5残差策略配合0.5倍预加载，在组3将严格六方向验证由4/6提升到6/6并独立重复；另五个平移的独立进程对照由24/30提升到29/30，修复5次、损害0次，完整六方向成功2/5→4/5。它是单参考上多个既有诊断平移的局部改善证据，尚不是跨物体、跨参考或未见扰动分布上的普遍改进。

这里的“原始候选0”是本工程L20生成文件中的候选，不是官方ShadowHand数据集候选；本地结果也不能直接与论文数据集成功率比较。

## 2. 原方法与本工程的关系

DexGraspNet原方法使用可微抓取能量优化，并通过Isaac Gym物理筛选；论文实验以ShadowHand为主体。它本来就包含动力学验证、关节限位相关能量及多尺度物体处理，不能把这些基础概念列为本工程首次提出。[原论文，第三节](https://tengyu.ai/assets/pdf/ICRA23_DexGraspNet.pdf)

本地官方代码可检查具体实现：

- [官方初始化](../external/DexGraspNet_official/grasp_generation/utils/initializations.py)。
- [官方验证与接触目标调整](../external/DexGraspNet_official/grasp_generation/scripts/validate_grasps.py)。
- [官方Gym验证器](../external/DexGraspNet_official/grasp_generation/utils/isaac_validator.py)：默认100步仿真，运行结束检查手–物体接触；外层再组合六方向及静态穿透筛选。运行参数应以具体实验为准。

本工程改变了手型、碰撞表示、控制执行过程和验收定义。因此“本地更严格协议下的表现”与“超过原论文方法”是不同命题。

## 3. 已实现的主要改进与扩展

|方面|当前实现及作用|当前证据边界|
|---|---|---|
|L20与mimic适配|按真实主动/从动关系生成目标，限制可行关节空间|已实现；不是新的通用抓取算法|
|小物体初始化|按缩放后几何尺寸设置初始化扩张距离，逐候选匹配scale|已实现；缺少统一条件下的成功率消融|
|SDF与物理联动验证|完整手部网格SDF、物理mimic、整物体SDF|模型表示扩展；未证明比凸碰撞更接近实物|
|抓取建立和长时验收|零重力闭合、稳定，再开启六方向重力保持10秒|可识别瞬时接触之外的滑移/掉落|
|生成参考上的残差学习|策略只输出有界、限速的主动关节偏置|杯子0组3已验证修复，跨平移待确认|
|接触与动作诊断|240Hz记录目标、实际关节、接触点/法向/力、mimic误差|支持定位失败，不能仅凭总力证明稳定|
|可信配对评估|新进程隔离、零–零复现、干预前前缀匹配、资产散列|排除已发现的部分过程混杂；不是物理真实性保证|
|局部参考细化|先关节、可选手腕；检查成功保留与跨样本取舍|单样本有效候选曾跨样本产生损害，未晋升|

### 3.1 从软约束到适合L20的可行空间优化

L20当前模型含21个旋转关节，其中16个独立关节、5个mimic从动关节。独立优化全部关节可能生成机械结构无法执行的姿态。

当前实现把从动角度约束为 `q_child = multiplier × q_parent + offset`，将从动关节梯度回传主动关节，并将从动限位反向收缩到主动关节可行区间；每次优化更新后执行约束投影。

实现入口：[joint_constraints.py](../grasp_generation/utils/joint_constraints.py)、[optimizer.py](../grasp_generation/utils/optimizer.py)。

研究意义是缩小“几何优化可行”与“实际机构可执行”的差距。证明其改善程度仍需同手型、同随机种子、同预算的有/无mimic约束对照。

### 3.2 小尺寸物体的初始化与比例一致性

保留原方法的`paper`初始化，另设实验性`scale-aware`分支：

```text
扩张距离 = clip(0.3 × 缩放后物体最小包围盒边长, 0.005 m, 0.02 m)
```

同一批不同scale的采样位置和最近点再按各候选比例匹配；保存的手腕平移已经对应物体scale，验证时不重复缩放。

实现入口：[initializations.py](../grasp_generation/utils/initializations.py)。原方法0.2m扩张是设计选择，不能表述为官方代码错误。当前分支是针对L20小物体的待验证改进，尚不能声称已提升生成成功率或收敛速度。

### 3.3 从短时物理筛选扩展到抓取建立与长时保持

当前主要Isaac Sim协议为：零重力闭合2秒、稳定1秒、开启指定方向重力保持10秒，物理步长1/240秒。六方向分别验收，全部通过才算该样本成功。

严格验收记录接触建立、重力阶段最大滑移≤5mm、最大转角≤15°、采样穿透≤1mm、末1秒持续接触及有限数值状态。mimic误差另外报告，不擅自增加为已有成功条件。

其价值在于区分“形成瞬时接触”“能保持参考姿态”和“在规定时间内抗重力稳定”。关闭重力抓取也限制了实验外推：这不是桌面接近、支撑转移、抬升与搬运的完整任务，也未实现全局避障轨迹规划。

碰撞方面，当前每环境采用22个手部SDF和1个整物体SDF，并施加物理mimic。物体网格仍来自恢复后的CoACD几何，SDF不会恢复原始表面已丢失的细节；质量、摩擦和驱动参数尚未通过实物标定。因此适宜称为“碰撞表示与执行约束更明确的验证”，而非“真实接触的准确复现”。

入口：[Isaac Sim SDF说明](ISAACSIM_L20_SDF.md)、[history.py](../isaacsim_grasp/history.py)。

### 3.4 从静态目标扩展为参考驱动的残差闭环控制

当前策略不重新生成整只手姿态，而在生成参考上输出16维主动关节残差：

```text
请求残差 = 0.15 rad × tanh(策略输出)
目标偏置 = 对请求残差施加0.2 rad/s的变化率限制
关节目标 = 对“阶段参考 + 目标偏置”施加限位与mimic投影
```

目标变化率限制不等于实际关节速度硬上限。物理执行仍由原生关节驱动与约束求解器完成，实际速度/力矩需独立记录。

v4只允许重力保持阶段干预；v5提前到零重力稳定阶段最后0.5秒，使策略有机会在加载前调整接触。当前已验证控制组合在预加载窗口将tanh空间请求乘0.5，重力阶段倍率保持1，偏置经过边界时连续、限速不变。这是固定检查点的控制干预，不是新的训练结果。

观测加入阶段时间、历史误差/失败相关状态等，当前维度120；失败采用历史严格判据及吸收逻辑。奖励包含低位移、低转角、低运动、小残差等稳定裕量目标。v4/v5沿用非负质量折扣形式 `positive / (1 + costs)`，避免此前负存活奖励的反例；奖励上升本身仍不能证明稳定。

入口：[control.py](../isaacsim_grasp/control.py)、[environment_v4.py](../isaacsim_grasp/environment_v4.py)、[environment_v5.py](../isaacsim_grasp/environment_v5.py)、[预加载倍率控制](../isaacsim_grasp/evaluation_interventions.py)。

其研究假设是：生成的抓取具备基础接触条件时，受约束的小幅反馈调整可修复部分动力学失败。当前是使用仿真状态的单参考策略，没有证明视觉输入、未知物体、未知抓取或实机上的泛化。

### 3.5 从通过率报告扩展为可追溯的修复证据

旧批量评估发现：即使显式初态和控制前缀相同，部分回合在策略干预前轨迹已不同。不能将后续成功差异全部归因于策略；也尚未证明唯一根因是warm-start。

当前使用一个新SimulationApp进程运行一个平移的六方向回合：先两个零残差进程检查完整轨迹复现，再运行策略进程检查干预前前缀一致。保存资产/检查点散列、实际初态、240Hz轨迹及逐方向首次失败。

报告区分`both_pass`、`policy_only`、`zero_only`、`both_fail`，同时统计完整六方向成功组数。六方向共享一个平移，不能当作六个独立平移样本。组3裁剪文件被误用为完整样本表的错误已单独记录，错误命名的group_000不计入跨平移统计。

入口：[check_isaacsim_isolated.py](../scripts/check_isaacsim_isolated.py)、[isolated.py](../isaacsim_grasp/isolated.py)、[finger_diagnostics.py](../isaacsim_grasp/finger_diagnostics.py)。该部分是实验方法与可复现性建设，不是策略网络创新。

## 4. 当前实验究竟证明了什么

### 4.1 杯子0组3：可信、可重复的局部修复

条件：原始杯子候选0、scale≈0.06、固定组3平移、原参考不改；v5检查点`mug0_residual_v5_20261106_100328/model_000200.pt`，预加载倍率0.5。

|方向|零残差双进程|策略及策略重复|策略最大滑移mm|策略最大转角°|
|---|---|---|---:|---:|
|gx+|通过|通过|1.223|1.798|
|gx-|通过|通过|0.675|1.047|
|gy+|失败|通过|1.660|2.292|
|gy-|通过|通过|0.756|1.553|
|gz+|失败|通过|1.535|1.737|
|gz-|通过|通过|0.562|2.295|

原参考gy+在重力后3.90417秒首次失败，gz+在50ms失败；策略完整保持10秒，原四个成功方向保留。零–零完整轨迹、零–策略干预前前缀、策略–策略完整轨迹均通过复现检查。

因此可以说：**在该已诊断样本上，固定残差控制组合可重复修复原参考的两个失败方向。**

不能说：已经证明全部平移/抓取都改善，或所有稳定裕量都更好。原成功方向中部分滑移、转角、穿透及mimic误差增加；未与简单常量偏置或规则控制器对照，尚不清楚学习反馈相对简单控制的额外价值。

证据：[组3逐方向对照](../data/experiments/mug0_v5_half_isolated_group03_20261108/POLICY_COMPARISON.md)、[复现审计](../data/experiments/mug0_v5_half_isolated_group03_20261108/reproducibility.json)、[独立策略重复](../data/experiments/mug0_v5_group3_repeat_20261108_071226/repeatability.json)。

### 4.2 必须保留的负结果与边界

- 杯子20小扰动下零残差本来就成功，策略全通过主要是工程正确性检查，不证明修复必要性。
- 旧v5二十平移记录104/120→113/120，但存在策略干预前过程分歧；不能用它作为已确认的RRL分布收益。
- 联合食指/中指MCP各+0.015rad的局部参考在组3由4/6→6/6；新五平移却原/改良均21/30，修复3次也损害3次。该参考没有晋升为普遍改善参考，其收益不计为RRL贡献。
- 五物体80候选的既有Isaac Sim筛选18/80全六方向通过，是本地协议下的数据汇总；生成批次、手型和验证条件不同，不能与原论文或Gym通过率直接比较算法优劣。
- 正确样本源下五平移复核已完成且全部过程检查通过：组0/1保留6/6、组2/4为4/6→6/6、组5为4/6→5/6，合计24/30→29/30、完整六方向2/5→4/5。残余组5 gy+仍在重力后33.3ms失败，开重力时接触力记录0；原24个成功方向的滑移、转角和mimic误差中位数增加，不能声称所有稳定裕量改善。这些旧诊断样本不是新盲测。误用裁剪文件的运行不提供新增平移证据。详见[工程复盘第43节](GRASP_RL_ENGINEERING_LOG.md)。

### 4.3 预加载保持消融：组5残余失败已局部修复

完成目录 `mug0_group5_preload_hold_20261108_093102`：冻结同一检查点，2.6–3秒保持已施加偏置，3秒连续恢复策略；原策略全程复现、干预前前缀及保持检查均通过。组5 gy+失败→通过，原策略5/6→保持变体6/6；该方向最大滑移46.728→1.167mm，预加载推移2.086→0.836mm。支持接触保持时序的局部控制假设，但变体仅完成单组验证，尚未跨平移确认，不能将其替换原五平移中的一个结果后声称整体全成功。

证据：[保持消融报告](../data/experiments/mug0_group5_preload_hold_20261108_093102/REPORT.md)。

## 5. 如何形成可用于研究报告的贡献

当前可表述为：**面向具有关节联动约束的L20，构建从DexGraspNet生成参考、SDF动态执行到受约束残差修复与可复现评估的工程研究流程，并验证一个可重复的方向失败修复案例。**

建议将后续研究贡献集中在一个可检验问题：

> 在保持物理与验收条件相同的情况下，参考驱动的受约束残差策略，能否在未用于选择控制方案的平移/抓取上提高完整六方向成功率，并控制原成功损害及运动代价？

达到该结论需要以下证据，而不仅是增加训练轮数：

1. **跨平移确认**：先完成已有样本的独立进程复核，再冻结方案使用新的未参与调参样本；报告以平移为单位的完整六方向成功率及不确定性。
2. **简单控制对照**：零残差、固定关节偏置/预加载与RRL在相同初态和严格判据下比较，判断是否确实需要反馈学习。
3. **干预时机消融**：重力阶段才启用、提前0.5秒启用、固定策略的倍率控制；区分训练版本与评估控制干预，避免混合解释。
4. **生成端消融**：相同优化预算和种子，对比paper/scale-aware初始化及mimic约束设置，报告可执行率、动力学成功率、时间和多样性。
5. **泛化和真实性**：独立抓取/物体、多训练随机种子、资产与参数敏感性，以及标定后的实物验证。跨引擎实验应分别控制碰撞、驱动和验收差异。

当前立即应做的是第1项已有样本复核；出现损害时先依据接触轨迹诊断，不把长训当作默认修复方法。其余项目是研究计划，不是已完成成果。
