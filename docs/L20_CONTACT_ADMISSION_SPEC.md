# 有效中指接触准入C：具体规则与当前候选

日期2026-11-16。当前为规则设计和已有结果的离线筛查，C尚未实现或运行，未新增优化/动力学。

## 1. 准入必须落在实际所选槽上

A固定171，B在80点中仅按原目标重选；C先筛选有效中指槽，再在合格组合中按同一目标排序。不能只要求“这只手有任意一点靠近”，而最终依然选一个悬空点。

C静态候选的逻辑：

```
source_geometry_admissible
AND region_annotation == reviewed_palmar_contact_region
AND selected_middle_point_is_near_object
AND approach_side_is_valid
```

其中1mm为当前实验接近尺度，不是承载稳定性或硬件标定参数。无任何合格组合时必须返回no_valid_middle_contact，不可自动退回B或放宽阈值凑结果。C改变了可行域，收益必须与A/B分开归因，不比较目标值大小来宣称优劣。

## 3. “经核查的夹持区域”具体指什么

对middle_distal原网格和4个候选点，显示局部坐标、点号、表面投影及网格法向，从掌侧和背侧查看。确认点落在计划压住物体的指腹/指尖接触面，而不是指背、关节孔、铰链外壳或边缘伪近点。不能因为连杆叫distal就将全部50/30个点当作指腹。

应绑定contact_points.json及该连杆原网格散列，记录标签palmar/dorsal/joint_shell/unknown、核查依据和版本。适用的是局部解剖区域，同一个211点在两个姿态中应有同一局部区域标签；但物体目标区域、接近侧和碰撞情况须逐姿态检查。

现有重选脚本--region-labels只记录注释，不实施C过滤，也不会认证标签。C入口需要独立实现，不能仅传入该参数就声称C生效。

## 4. 点距离和法向怎么检查

优先采用同源、明确闭合/符号可靠的物体碰撞表面复核点的外侧距离，主实验从物体外侧进入1mm带；不能将明显内部点用abs(distance)伪装成接触。原生成器正内负外时，临时外侧带为[-1,0]mm，但原符号不作最终认证。

原返回法向是生成器的距离方向数据，不等于已核实的手指表面法向或物理接触法向。应分别显示手表面外法向、物体外法向及接近方向，确认对向接触是否合理。主C先记录这个诊断，不偷偷加入未经标定的45度等新硬阈值；若要增加法向限制，另列实验版本/参数。

## 5. 保留的共同护栏与新增检查边界

原mesh_gap 1mm实验参数、权重、固定其余3槽、MCP/PIP网格、mimic、物体采样、自碰撞拒绝、原穿透非增加全部不动。几何不会因点号重选而改变，故可复用源静态审计，但不能把未知改成通过。

中指点进入1mm并不证明全手合格。最终仍需其他手指真实接触组合、原网格自碰撞、手物绝对穿透、开放目标包含处理，以及现有acquire真实张开初态/闭合曲线检查。

分开输出三种状态：

- contact_candidate_admitted：有效区域和所选点接近/接近侧通过；
- static_geometry_admitted：完整独立绝对几何通过；
- execution_admitted：闭合路径及必要执行检查通过，可以进入600g验证。

任一关键字段unknown/pending都不能自动作true。原穿透不增加只相对起点；起点可能已经超严格1mm标准。

## 6. 最后才做承载对照

在原始、B参考和C参考之间做同600g、六方向、2+1+10秒协议，参数和资源一致。点位接近不代表夹紧，中指是否实际建立法向力、保持接触且减小滑移才是执行证据。若C没有合格参考，当前不启动该组试验，也不能伪造36个结果。
