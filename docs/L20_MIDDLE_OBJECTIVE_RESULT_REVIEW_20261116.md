# 中指目标函数完整诊断复盘（2026-11-16）

来源：`data/experiments/l20_middle_objective_20261116_124301`。status完整；候选22/18/31、每模式8组四点探针、2000固定物体表面点、scale1、seed1。只评估冻结姿态，未生成新抓取或进行动力学。

## 现象—机制分析

### 假设一：缺少中指接触是一个机制，但分组不能自动解决

|候选|不含中指的平均MCP总梯度|分组平均MCP总梯度|分组指向闭合/张开|解释|
|---|---:|---:|---|---|
|22|+.524728|+.950664|3/8、5/8|点位质量与几何方向重要，仅包含中指不足|
|18|+.348919|−3.41892|8/8、0/8|有接触吸引时能克服当前排斥，适合局部修复对照|
|31|+11.0406|+7.2184|0/8、8/8|穿透项占主导，不应强制闭合|

正梯度表示下降方向减小角度；22和18的MCP在0下限，张开请求被投影阻止。31已有MCP弯曲，开角可能是避碰响应。冻结探针不是旧最终接触选择，不能断言旧候选未选中中指。

22分组8例中，距离项有5例产生闭合梯度，其中2例被排斥抵消，最终仅3例总梯度闭合。另3例都选中了`middle_middle`，距离项梯度约+1.94、+2.23、+1.78，本身就请求张开。因此需要检查接触区域及MCP/PIP耦合几何，不能把“选中中指”视为有效夹持。

### 假设二：同体和相邻点对不是当前MCP张开的主要来源

22/18/31的原排斥与拓扑过滤MCP总梯度几乎相同；同连杆及相邻连杆MCP梯度只有浮点级别。22跨指加权MCP梯度+1.05966，掌部−.534925，净+.52473。18跨指+.882054、掌部−.533133，净+.34892。

这修正了“删同体/相邻就能解决MCP”的预期。对PIP，相邻项的加权梯度分别为−.264475、−.069999、−.679526，仍会影响弯曲；不能把MCP结论推广到所有关节。

原20mm关键点排斥是否过于保守仍待评估。22食指/中指近节双向顶点采样最近距离约6.31/6.79mm，不能用这些近似值认证无三角形相交或为安全间距定标；更不能把20mm直接改成另一个经验数而放弃实际避碰审计。

### 扫描证据：不能统一增加MCP

MCP从当前值增加.1rad，80个中指接触候选的最近绝对距离：22由23.121→24.398mm，18由29.234→27.479mm。22的这一小段闭合没有改善最近点距离；这不证明整个关节范围不可达，也不代表每个接触点都变远。

31中指已有11/80个候选点处于1mm内。进一步增加.1rad后，原E_pen从.0032946→.0278165m（采样深度之和），中指接触候选的原始符号内部值最大从1.046→5.668mm。开放物体上的符号值不是物理穿透认证，但扫描与高穿透梯度都反对盲目强制弯曲。

31的加权E_pen MCP梯度为+11.73677，远大于分组距离项−3.82496和自排斥约−.69613；故其总梯度张开主要不是自排斥造成。

## 补充核查：显示模型与生成E_pen模型不同

当前`grasp_generation/utils/hand_model.py`约240–268行对每个连杆构造`combined_mesh.convex_hull`，并将凸包写入`face_verts`供生成E_pen使用；`vertices/faces`保留原网格供HTML显示。该源文件散列与本次config匹配，不是诊断后改动。

此前“局部顶点/准备输入一致”只覆盖原始显示网格和Sim准备网格，没有证明生成E_pen的面集合与它们相同。这是模型层次的补充，不能继续把“原始顶点相同”解释为生成与Sim的碰撞表示完全一致。

本轮仅做CPU有界几何查询，使用本次保存的2000点，结果写入实验目录`REVIEW_GEOMETRY.json`：

- 22：凸包内1点，位于无名指远节，也位于闭合原网格内。
- 18：凸包内3点，位于无名指远节/拇指掌骨，也被对应闭合原网格包含。
- 31：中指远节凸包内2点，闭合正体积原网格射线包含测试仅包含其中1点。其余掌部/拇指开放网格不作可靠包含判定。
- 31中指两点进一步局部查询：1575号点凸包深度.8043mm，原网格内距表面.5416mm，凸包加权MCP梯度约+8.1327；1690号点仅凸包内、深度.09949mm，原网格外距表面.10430mm，凸包梯度约+3.6040。两点合计接近原+11.73677。原网格内那个点的固定最近点局部深度梯度仍约+7.7336。

这表明31既有凸包额外排斥，也有原网格内部样本；不能把其全部穿透损失判为凸包假碰撞。上述是保存采样点的局部几何证据，尚非新完整碰撞损失或动态结论。

## 验证边界

各候选诊断能量与原函数值一致，最大独立梯度绝对差约3.09e-4并满足逐项绝对/相对容差；这验证代数复现，不认证原距离模型物理正确。

31自排斥MCP有限差分−.04292与解析−.06961差约.02670，需要检查阈值切换、步长及float32消去；暂不把该项数值当高精度响应预测。其穿透项主导结论还有独立分项和扫描证据。
