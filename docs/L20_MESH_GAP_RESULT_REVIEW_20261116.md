# 实际网格间隙对照结果复盘

来源：`data/experiments/l20_mesh_gap_compare_20261116_132642`，完整60个静态网格构型，候选22/18各30个。原/新目标使用同一固定grouped4接触点、原网格、2000物体采样和共同护栏。未优化器训练、未验证动力学。

## 现象：外观改善得到数值支持，但中指尚未有效贴近

|候选|原始最近距离mm|legacy选择mm|mesh_gap选择mm|mesh_gap MCP/PIP/DIP rad|
|---|---:|---:|---:|---|
|22|23.1214|23.1214|10.9347|1.0000 / .77355 / .68977|
|18|29.2335|25.6734|5.8616|.7000 / .93266 / .83165|

22新选择比原始减少约52.7%，18减少约79.9%；18比本轮legacy选择减少约77.2%。比较的是80个中指接触候选的最近距离，不是选中接触点必然达到此距离，更不是接触力。剩余10.93/5.86mm仍大于1mm接近阈值，不能称抓取成功。

## 共同约束确实生效

- 22：24/30通过当前护栏、4个因原手物穿透代理增大拒绝、2个因自碰撞拒绝。
- 18：14/30通过、16个因穿透代理增大拒绝；后者先被拒绝，未进一步计算自碰撞，不能据此说所有18构型都无自碰撞。
- 两个新选中构型均未检出规定非邻接对的表面相交/接触或可判定包含，所有检查对的截断间隙均达到至少1mm。
- 22新选择的E_pen采样和及最大采样内部值均为.000221479m，与原始相同；18采样和.00130793m、最大值.000756464m，与原始相同。和、最大值不是同一个指标。
- 22原MCP1.0/PIP不变的拇指碰撞构型被拒；新选择将PIP减.2，DIP随mimic减小，并通过共同护栏。不能把此前直接加MCP的构型当新选择。
- 22新选择有7个开放目标包含方向未知，18有6个；所以不认证完整实体无自碰撞。护栏沿用手部凸包及2000点，不认证真实手物穿透无增加，也未检查连续路径。

## 分析：两项问题已分离

1. 在共同构型/可行域/接触点下，仅改变自排斥定义就改变了两候选的选择，支持原20mm关键点排斥影响当前选择的解释；不是通过放弃检出的真实碰撞换取更好外观。
2. 新目标仍未优先选到有效接近姿态。候选22已有行20（MCP=.8/PIP=1.17355，DIP自动mimic）距离.6419mm、通过护栏，但新目标值10.97298高于选中行24的10.19564。候选18行43（MCP=.6/PIP=1.13266）距离.1054mm、通过护栏，但新目标值14.44971高于选中行45的14.14273。
3. 最低合成能量不等于最近中指距离。距离项只针对固定四个点，另有力闭合等项；当前中指槽固定为middle_proximal的一个点，不能代表远节等所有可达接触区域。尚未逐项重建上述排序差异，不应仅凭距离就归结为某一项。

这是两个候选、一个固定接触集合的静态网格选择证据，尚不证明端到端生成普遍改善或新优化器收敛。

## 下一步

优先针对同一60构型补齐选中四接触的逐点距离、法向和E_fc/E_dis，比较“新目标选中”与“已接近但未选中”的4行（22的24/20、18的45/43）。先解释为什么近接触没有被选中，不再盲加自碰撞权重或闭合角。

然后保持真实间隙模型/共同护栏不变，只让中指接触槽在经过区域和可达性筛查的候选中重新选择，与固定槽作配对；或将中指有效接近作为明确的几何准入条件，再比较其余目标。不得用任意背侧最近点替代有效掌侧夹持。修改前须保存原配置和实际接触索引。

若能稳定选到接近且几何合格的构型，再用原物体同源闭合碰撞代理独立复核手物几何及路径，随后比较原始/legacy/new参考的600g六方向动力学。当前不应把两个更好看的HTML直接汇报为成功稳定抓取。
