# L20中指异常：接触覆盖与自碰撞排斥的对照方案

状态：固定姿态机理检查已于2026-11-16实现，见[诊断代码与运行命令](L20_MIDDLE_OBJECTIVE_DIAGNOSTICS.md)。生成器改动及四组重新优化尚未实现，未启动新优化或动力学。沿用[已完成的诊断证据](L20_MIDDLE_FINGER_DIAGNOSIS.md)。

## 要回答的问题

- H1：全局4点未给中指提供足够的接触吸引，使它在优化中被忽略。
- H2：20mm关键点排斥对正常近距离结构施加了不适当的排斥，阻碍中指参与。
- 两者可能相互作用：缺少吸引时，较小的排斥梯度也可能主导关节更新。

四接触点本身不是错误，抓取也不要求五指或每节都贴物体。本实验检验当前任务是否因缺少中指有效接触而退化。既有证据没有保存候选22的最终接触索引，不能反推其真实选择。

## 1. 冻结输入并补齐记录

对象为power-drill-clean-l20、scale1，沿用原OBJ及同坐标闭合碰撞代理、当前L20 URDF、16独立关节/5mimic。保存网格、代码、配置散列。保留原32候选与旧验证输出。

新结果保存：每个接触槽的索引/连杆/手指、世界位置、物体表面最近点及法向；每指有效接近比例；四指MCP/PIP/DIP；各能量项；独立关节空间的分项梯度；候选初始化、物体表面采样、随机序列及投影前后更新。

不能仅增加保存最后一次接触索引：优化过程也应周期记录，以区分中指从未被选中和曾被选中后放弃。

## 2. 先做固定姿态的梯度与局部扫描

诊断样本用原候选22和18，另取一个中指MCP明显弯曲的候选作对照。这是局部机理检查，不能替代从原初始化重新生成。

固定手腕和其他独立关节，分别记录：

`g_total = g_fc + 100*g_dis + 100*g_pen + 10*g_spen + g_joints`。

对PIP等mimic源关节，应先按mimic倍率将从关节梯度回传，再比较独立自由度；同时记录RMS预条件和上下限投影后的实际请求步长。原始梯度非零不等于关节最终会动。

旧接触索引缺失时，新抽取的固定接触集合只能称为受控探针。分别使用不含中指和含中指的多组固定接触集合，不将探针结果冒称旧优化轨迹重建。

将自碰撞分解为同一刚体、URDF直接相邻结构、同指非相邻结构、不同手指、手指与掌部；对每类同时记录损失值和MCP/PIP方向导数，并进一步列出贡献最大的具体连杆对。

关键辨析：同一刚体内部点间距离恒定；只改变MCP、保持PIP/DIP时，MCP下游三节共同刚体旋转，其相互距离也不变。因此这些项的大损失值不代表它们对MCP有张开梯度。当前+.05247导数的具体来源仍需分解；跨指排斥也可能是合理的真实避碰，必须核对网格距离/交叠。

局部扫描MCP相对当前值+0.015、+0.05、+0.10rad（限位内），保持mimic关系，比较各能量项、中指接近距离、手物穿透和真实自碰撞。用小步长单边有限差分核对处于下限的导数。扫描不是强制将目标角设为这些值。

判断：加入中指接触后吸引梯度出现而不增加穿透，支持H1；只有合理过滤特定点对后张开梯度消失且真实碰撞仍合格，支持H2；若弯曲很快导致真实穿透，则须进一步检查接触位置与可达性。

## 3. 四组配对生成对照

|组|接触选择|自碰撞项|目的|
|---|---|---|---|
|A|原全局4点|原20mm全部点对|可复现的基线|
|B|分组4点|原项|检验接触覆盖作用|
|C|原全局4点|合理过滤点对|检验排斥点对作用|
|D|分组4点|与C相同|检验两者的交互作用|

B/D保持接触总数4，槽位分别来自拇指、食指、中指及无名指/小指联合候选池；这个组合是诊断配置，不宣称对所有物体最优。初始化和后续重采样均须遵守槽位分组，不能只在初始化加入中指。固定点数避免把覆盖收益与增加接触数量混淆。

C/D先仅改变点对掩码：屏蔽同刚体和经过几何核查的允许相邻近距离结构，其他阈值、权重不改；不得屏蔽所有同指或跨指碰撞。直接相邻关系本身不意味着任意角度下的全部网格交叠都安全，应配合实际碰撞审计。如仍由跨指20mm排斥主导而实际网格未碰撞，再另开阈值/几何避碰对照，不偷偷混入C。

四组读取相同初始手腕、关节、物体采样和候选编号。尽量保存每步接触选择的均匀随机数及退火接受随机数，按各配置映射；只设置相同seed不能防止不同分支消耗随机数导致错配。不同目标导致不同接受轨迹是实验效应，应保留。

先8个配对初态、固定1000步作筛查。若连中指接近和碰撞合法性都没有改善，停在诊断阶段。通过后再用32个配对初态、固定6000步，并以另一组独立种子确认。均由用户按最终实现命令启动，本方案不自动运行或监控。

## 4. 判定依据

逐候选比较中指是否被选中、中指接触候选到物体距离、有效接近点数/比例、MCP零下限停留比例、其他手指的接触保留、手物穿透和真实自碰撞。1mm接近阈值只作几何诊断，不是承载接触。

不要用各组自己的最低能量前16直接排名：点对掩码会改变能量常数和目标含义。使用相同候选编号及固定几何条件，报告全部配对候选；若限制验证预算，须预先规定共同的编号/筛选规则及拒绝数。

|结果模式|解释与后续|
|---|---|
|B改善、C无改善、D近似B|接触覆盖更可能是主要因素|
|C改善、B无改善、D近似C|不适当排斥更可能是主要因素|
|B/C各有改善，D进一步改善|两者共同作用|
|B/C均弱，只有D改善|存在交互，单项改动不足|
|中指贴近但穿透或其他指退化|未解决抓取，不能仅凭外观接受|
|四组均无改善|检查中指可达区域、手腕位置及接触法向，不继续盲加刚度|

上述是定性决策逻辑，应看逐初态配对及多个种子，而非单个最佳候选。

## 5. 最后做同条件动力学验证

固定600g、摩擦3、Kp5/Kd0.05、力矩上限1Nm、SDF256、240Hz、相同碰撞代理。零重力闭合2秒、稳定1秒，六方向重力各10秒，方向以相同初始物体/世界坐标为准，逐方向独立进程。沿用既有最大滑移5mm、转角15°、穿透1mm及末尾持续接触等严格判据。

报告每个方向成功数、六方向全通过数、准备阶段失败、重力阶段失败、异常，以及逐指接触建立和脱离时序。不能只报告六方向全成功。先分清张开初态/闭合路径穿透与最终保持能力；已有候选22首步穿透超限，不会因中指接近自动消失。

只有几何合法、承载改善且原成功方向未明显受损，才保留新配置。此阶段不引入RRL、不改增益或验收阈值，避免混淆生成质量与控制补偿。
