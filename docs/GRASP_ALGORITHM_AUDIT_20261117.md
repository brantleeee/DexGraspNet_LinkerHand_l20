# L20电钻抓取生成算法审计（2026-11-17）

**结论：用户怀疑有依据。当前适配流程存在确定的模型/目标缺口；不能再以增加样本量作为主要修复。尚未发现足以解释全部现象的退火状态恢复或mimic链式梯度错误，也不能据本审计直接否定原DexGraspNet方法。**

本轮只做代码审计、CPU小实验和测试，未改变生成目标/模型、重启任务或新增长生成。读取一次当前128候选批次状态为generating，尚无该批最终结果；未持续监控。

## 1. force_mesh_sdf并没有让手部穿透项使用原始网格

入口传`force_mesh_sdf=True`，但HandModel的URDF建模分支仍无条件做`combined_mesh.convex_hull`，把凸包三角面写入`face_verts`；`cal_distance`始终查询它。参数名/旧注释不能替代运行时几何审计。

|link|原始面数|生成距离查询面数（等于凸包）|
|---|---:|---:|
|middle_proximal|16146|1028|
|middle_middle|16090|2210|
|middle_distal|18850|6920|
|base_link|50832|4060|

对闭合的middle_middle/distal各取4096个包围盒内确定性随机探针，分别有1640/853点在凸包内而被原网格射线包含判断为外；选取的例点距原始表面约4.887/3.155mm。该比例的分母是包围盒探针，不是生成物体采样点，不能推断对应比例的生成结果发生误判。原网格可能含多部件，射线分类也不代替硬件实体认证，但几何代理差异确定存在。

因此，显示原STL或在MuJoCo原STL SDF上不碰撞，并不意味着生成E_pen会允许同一构型。旧注释声称“凸包保证SDF100%准确”是不成立的：它最多构成闭合的凸包代理，不等于原物体形状。为保护旧资产SHA和正在运行任务，本轮未直接编辑该源文件或替换缓存。

## 2. 四个全局随机槽不等于四指夹持

初始化和每次Annealing重采样都允许从全部403点均匀、有放回选择；没有指别或区域约束。槽可以重复并集中于两指。此前roots12批次实际中指参与11/32、前16仅5/16。

中指未被选中时，E_dis、E_fc、新E_normal都可以对中指给出零梯度；修改手部法向本身不会补上接触目标。该问题是当前目标缺少参与约束，不是点库没有加载，也不是增加迭代数必然能解决。

扩大到128提高搜索覆盖，但不能保证消除允许中指悬空的低能量解。另外RMS预条件的平方梯度均值跨batch共享，所以批量大小还会改变归一化，不是简单复制128个完全独立优化器。

## 3. E_fc是平衡残差代理，不是完整力闭合/600g承载证书

当前公式计算各接触法向产生的合力、合矩平方和，未显式求摩擦锥下的可行接触力或抗扰动wrench空间，也未引入600g重力和电机力矩约束。

严格按现有公式构造：在x轴两侧各取一个位置，每个重复两次，法向沿相反x方向。得到：

- 4槽、2个唯一位置；
- E_fc=0；
- 四个法向力wrench的矩阵秩为1，力矩部分全为0。

这说明“合力合矩恰好抵消”不足以证明全面抗扰动能力。秩1例使用的是法向力射线模型，不等同于已加入摩擦锥后对该具体几何的全面物理判定。不能把这个反例夸大为原论文全部优化方法无效，但应停止把低E_fc当作六轴稳定的充分条件。

## 4. 跨指20mm排斥仍偏离真实几何

最近12组根部豁免只删除明确的根部link对；middle_proximal/index_proximal及middle_proximal/ring_proximal仍属于不同手指，继续施加20mm关键点排斥。

前轮真实接触审计中，候选21没有中指吸引目标，自排斥加权MCP梯度约+1.029，下降方向张开；候选7已选中中指但跨指排斥仍推动根部张开。原网格间隙和后续整手MuJoCo扫描都没有在所测路径检出相应严重跨指干涉。这支持代理过保守，不支持直接关闭全部自碰撞。

还须纠正一个容易误解的方向：某些掌根—中指排斥在当前姿态贡献的是闭合梯度。删除根部项不保证中指更弯，可能去掉一个闭合方向的贡献。只能用分项与几何对照判断，不按“删约束必改善”推断。

## 5. 新法向项使用不完整的空间法向梯度

TorchSDF自定义autograd明确把sign、normal、closest_point标为不可微，只向查询点传回距离梯度。因此E_fc不会对“物体法向随查询位置变化”完整求导；新增E_normal对手部FK旋转可微，但对物体查询法向的空间变化不完整。

先前2候选短检和立方体符号核对证明了链路/符号，并没有证明该项在开放电钻网格上形成完整、平滑且正确的姿态优化梯度。这个限制继承了本地TorchSDF接口，新法向项也受影响。应做固定姿态、固定接触的受控消融，不能继续只调法向权重和样本量。

## 6. 已检查但未复现错误的部分

- **混合接受/拒绝恢复**：小型手模型与真实L20均测试一行接受、一行拒绝；恢复后与新鲜FK重算的点、世界N、pose梯度一致。真实L20测试含新法向目标，但物体N使用常量，不是全部TorchSDF/穿透分支的穷举。
- **mimic投影/链式梯度**：PIP/DIP依赖梯度回传与独立变量有限差分匹配，生成结果的mimic误差也很小。
- **新法向旋转**：只旋转不平移，FK梯度可传播。
- **根部mask**：只删除12个无序link对（24个有向位置），跨指及远节—掌体保留。
- **能量与保存值**：此前实际GPU短检查验证过分项重组和保存身份。
- EMA系数形式与本地官方兼容optimizer一致，不能仅凭与常见RMSProp习惯不同就指为本次改坏的代码。

本轮共8项不同测试通过：算法审计4项、法向/FK2项、根部mask2项。测试通过不是整个生成器正确性的证明。

## 7. 建议的修正顺序

1. **先统一穿透几何**：用独立新版本显式声明代理；优先对闭合link验证原非凸几何，对开放link单独修复/核查，不能无检查直接把全部凸包换成开放三角面。
2. **约束接触选择**：初始化与重采样同时保持手指分组，限制重复槽；对选中点引入明确的接近/合法区域准入，而不只看任意中指点接近。
3. **修正跨指排斥**：以实际几何间隙或经过验证的距离代理替代全对20mm排斥，保留用户指定的根部豁免以及其余真实避碰护栏。
4. **加强筛选并检验新法向项**：将E_fc保持为代理或引入摩擦/负载受力约束；分别评估法向项开/关和几何修正后的短优化，最后按600g六方向动力学筛选。

先在相同少量初态、相同接触槽和采样上形成可归因对照，再做6000步批量。不要同时更改一堆权重后仅看排名，也不要强制四指角度相同来掩盖目标缺口。
