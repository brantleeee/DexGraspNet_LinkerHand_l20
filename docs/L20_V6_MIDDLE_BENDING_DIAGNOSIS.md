# v6电钻生成：中指根部不弯曲诊断（2026-11-17）

诊断对象：`l20_v6_clean_drill_20261117_135743`，L20右手、v6 403点、清理电钻scale1、32候选、6000静态迭代、法向权重1。生成任务已完成，URDF可行32/32，静态几何阈值6/32；没有新动力学成功结论。

**结论：主要异常在MCP根部，而非中指完全不运动。实际目标允许中指不参与；对已探查的候选，旧20mm关键点排斥还会推动根部继续张开。不是单纯改法向就能解决，也未发现mimic将中指锁死的证据。**

## 1. 实际32个结果

|手指|MCP中位数 rad|MCP=0数量/32|PIP中位数 rad|
|---|---:|---:|---:|
|食指|0.439806|1|1.005104|
|中指|0.025857|13|0.933901|
|无名指|0.190768|4|0.905225|

中指PIP/DIP已经弯曲，但根部常留在伸展位置，因此外观看起来不像其他手指包住物体。中指MCP仍有候选能到0.7404rad，说明该自由度没有被全部固定。

## 2. 排除明显的关节/mimic配置锁定

四指MCP_pitch均绕局部+Y，范围0–1.4rad；PIP均0–1.57rad；DIP均遵循`0.8917*PIP`。中指MCP为独立优化变量。32个结果四指最大mimic误差约9.51e-8rad，生成可行性32/32。

这只说明本工程配置与保存结果没有明显锁定/违约，不代表硬件URDF已经物理标定。也不能要求四指角度一模一样：正确目标应是合理接触、避免碰撞和稳定承载。

## 3. 接触目标仍没有保证中指参与

真实保存的最终接触点中，中指仅被选中9/32；能量前16中只有5/16，其余11个没有中指槽。

排名第一的原候选21，4个槽为：拇指远节、拇指远节、食指近节、食指近节。原候选16为：小指近节、拇指远节、小指近节、拇指远节。槽数是4，但可以集中到两根手指，甚至重复同一手指/连杆。

新法向项只作用在选中的点上，不是所有403点同时受约束。候选21/16中，E_dis、E_fc、E_normal对中指MCP和PIP的局部梯度均为0。修改中指远节法向，不会给这两个候选凭空增加弯曲驱动。

## 4. 实际梯度：什么在让中指张开

固定保存姿态、腕位和实际保存的接触索引，按生成原权重分解。下表正梯度意味着局部下降方向减小MCP，即进一步张开。

|原候选|MCP rad|100E_dis梯度|10E_spen梯度|E_normal梯度|主要现象|
|---|---:|---:|---:|---:|---|
|21，排名1|0.17699|0|+1.02874|0|中指没有接触目标，排斥推动张开|
|16，排名2|0|0|+0.94468|0|相同机制，根部停在下界|
|7，排名3|0|+0.25128|+2.20954|+0.02794|已经选中两个中指点，但多个项仍偏好根部张开|
|30，排名6|0.53447|−1.14714|−0.85241|−0.15063|中指有弯曲，接触和法向项在当前局部推动继续弯曲|

自排斥的主要来源是**不同手指之间**，不是同一连杆常数项或相邻连杆：

- 候选21：不同手指贡献+1.57228，掌根/中指贡献−0.54354；同link和相邻link贡献约1e-6。
- 候选7：不同手指+2.74340，掌根/中指−0.53387。
- 候选21中最强两对：middle_proximal/ring_proximal约+1.10025；middle_proximal/index_proximal约+0.47202。

因此本轮不能再把“直接删掉同link/相邻结构排斥”当作解决方案，它们对这几例MCP的梯度几乎为0。现有20mm全对关键点距离代理仍可能把几何合理的近邻结构当成需要分离的点。

固定其他关节后，候选21的中指MCP增加0.4rad时，中指候选点最近距离代理约19.18→9.55mm，**但总目标约75.02→78.02变差**，自排斥增大。当前目标没有选中中指，自然不会奖励它更接近物体。

这些梯度是冻结姿态的局部证据，不是复原6000次RMSProp历史轨迹。对自排斥做了有限差分方向复核，边界/分段点及float32有数值差异；没有宣称每个分项有限差分都完全匹配。

## 5. 与真实网格的对照

对候选21和7，在原MCP及增加0.2rad的位置，检查以下三组原始STL表面：

1. middle_proximal/index_proximal；
2. middle_proximal/ring_proximal；
3. middle_distal/ring_middle。

共12项，表面间隙均**≥1mm**，双向包含检查未检出包含；这些具体连杆对仍产生显著20mm关键点排斥，支持该代理在这些测试位置过于保守。采用三角面对归一化处理微面容差，2项尺度/平移及相交测试通过。

检查仅覆盖指定连杆对、指定离散姿态，不是全手或连续闭合路径无碰撞认证；候选7继续弯曲时手物穿透代理也可能增大，不能强行加MCP下限。

## 6. 本轮边界

- 真实接触点、E_dis/E_fc/手部N目标和自排斥均可按保存信息重算。
- 原生成未保存物体采样云。本轮E_pen使用新固定2000点云，明确保存，不能声称其数值或梯度是原优化历史的精确重放。候选7新采样E_pen对MCP有正梯度，但本轮主要结论不依赖它独立成立。
- 原电钻是开放网格，符号距离仍不是独立实体穿透认证。
- 没有关闭避碰、修改生成器目标、重跑生成或做动力学。

## 7. 下一步最小对照

先保留v6原结果，建立两个独立对照：

1. **接触参与对照**：固定4个槽的手指分组（拇指、食指、中指、无名指/小指），在初始化和每次接触重采样中都保持分组；只保证槽属于中指仍不代表有效接近，还需记录选中点距离和接触位置。
2. **几何排斥对照**：保留真实网格避碰护栏，在已定位的不同手指连杆对上，以实际网格间隙代替20mm关键点距离代理；不得整体关闭自碰撞，也不复用未尺度复核的旧间隙数值。

分别比较参与槽、MCP角、选中点距离、原网格自碰撞/手物穿透和目标分项，最后再组合改善项并做600g动力学。不能只看中指“弯得像其他手指”就验收，也不应先加优化步数或调大抓取力。
