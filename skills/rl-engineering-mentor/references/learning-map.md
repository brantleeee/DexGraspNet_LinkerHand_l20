## 当前最值得先练的四步

1. **先读懂v2，而不是先继续调PPO。**
   跟踪 `environment_v2.step → history.record → reward/terminal/passed → runner样本屏蔽`，解释一个刚滑移6mm又恢复的样本为什么仍失败。
2. **验证策略确实只在重力阶段作用。**
   解释为何闭合阶段要同时屏蔽动作、清零滤波状态、排除训练样本；只把动作乘0并不自动排除PPO学习。
3. **把基线作为测量工具。**
   检查同参考、同噪声/种子、同时长下零残差与策略的分方向结果，而非比较不同时期的训练奖励。
4. **用证据决定是否长训。**
   提前写下继续条件：基线可复现、策略未破坏原能力、目标扰动下指标改善且数值/约束可接受。
   具体容差、样本数和风险按任务决定，不预设万能通过率。

## 建议练习与验收

- 用末秒窗口例子说明：接触在窗口之前丢失可恢复，窗口内丢失可能已无法补足；以剩余步数而非“第一次接触丢失”判定。
- 将PPO中 `delta = reward + gamma * next_value * (1-terminal) - value` 对应到项目张量，区分批量统一复位和每环境逻辑终止。
- 从一份CSV手工统计窗口通过率，再与TensorBoard核对；解释空缺的value_loss点和`update_performed=0`。
- 在一个小实验里只改变当前待验证机制，先写预期结果；失败时更新假设，不立刻叠加更多调参。

这些是练习，不是运行任务的前置考试。用户只要命令时，先交付命令，再简短指出应观察什么。
